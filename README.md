# Coupon Redemption System

## Create Coupon

Enter:

* Title
* Code
* User Email
* Max Redemption
* Expiry Date

Click **Create Coupon**

## Redeem Coupon

Enter:

* Coupon Code
* User Email

Click **Redeem**

## Features

* Create coupon
* Redeem coupon
* Prevent duplicate redemption
* User who created coupon cannot redeem it
* Handle concurrent redemption requests
